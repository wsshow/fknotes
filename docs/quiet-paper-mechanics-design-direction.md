# FKNotes「静谧纸械」设计方向

> 英文名称：Quiet Paper Mechanics
> 文档状态：设计方向基线，待通过交互原型验证
> 适用产品：非空笔记 / FKNotes
> 建立日期：2026-07-24

## 1. 文档用途

本文档用于统一 FKNotes 后续界面的视觉语言、空间模型、交互隐喻和落地边界。

- 产品功能、页面范围和正式状态仍以 [`ui-design-feature-inventory.md`](./ui-design-feature-inventory.md) 为准。
- 本文档不增加新功能，也不替代产品功能清单。
- 当视觉创意与可用性发生冲突时，优先保证操作清楚、状态透明和内容可读。
- 后续主页、编辑器、本地助手、设置、本地模型和分享图设计应从本文档提取共同规则，而不是逐页复制参考图。

## 2. 方向结论

该方向正式命名为「静谧纸械（Quiet Paper Mechanics）」。

它不是简单的纸张拟物风，也不是复古记事本主题。它的核心是：

> 用纸页、卡轮、刻度、定位点和展开关系，建立一套可预测的界面物理规则。

用户面对的不是一个排列了许多通用卡片的页面，而是一台安静、精密、用于保存私人记忆的纸页装置。笔记是装置中的内容页；浏览、搜索、打开、选择和写入，都通过一致的空间变化表达。

该方向与 FKNotes 的产品定位具有较强一致性：

- 纸页和本地装置感强化「内容在我的设备里」。
- 单篇聚焦降低首页噪音，适合私人笔记而不是公共信息流。
- 机械定位感表达可控、可靠和有边界的本地 AI。
- 展开、插入和推出等动作可以自然承载编辑、AI 写回和分享图流程。
- 与常见的卡片列表、彩色文件夹和云端工作台型笔记产品形成明显差异。

## 3. 核心设计原则

### 3.1 物理规则优先于装饰

纸张弯曲、刻度移动和页面展开必须表达真实的信息或操作状态。

- 弯曲的相邻页表示可以继续浏览。
- 中央展平页表示当前聚焦。
- 两侧刻度表示位置和运动。
- 图钉表示置顶。
- 纸条尚未插入正文表示 AI 内容仍待确认。

不为单纯“看起来精致”添加无意义的铆钉、缝线、折角或机械零件。

### 3.2 当前内容优先

主页默认只让一篇笔记成为视觉中心。其他笔记保留足够的标题预览，帮助用户理解前后关系，但不与当前内容争夺注意力。

### 3.3 边缘承担工具，中央留给内容

- 品牌、位置索引和相邻笔记可以位于左右边缘。
- 搜索入口可以位于顶部边缘。
- 新建操作位于右下拇指热区。
- 中央主体区域优先展示当前笔记。

### 3.4 动效必须有定位感

动效用于说明页面如何移动、展开、插入或退出，不做持续装饰动画。每次页面切换都应有清晰的开始、定位点和结束。

### 3.5 特点不能增加关键操作成本

所有关键功能都必须有可点击入口，不能只依赖用户猜测手势。

- 搜索既支持下拉，也支持点击拉手。
- 相邻页既支持滑动，也支持点击。
- 快速定位不能只依赖连续滑动。
- 减少动态效果后仍可完成全部操作。

## 4. 核心空间模型

主页使用「纵向卡轮」作为主要空间模型。

### 4.1 页面层级

1. **应用外壳**：固定的品牌书脊、顶部搜索拉手、右侧工具节点和新建入口。
2. **卡轮轨道**：承载笔记顺序、当前位置和上下滚动。
3. **中央纸页**：当前聚焦的笔记。
4. **相邻纸页**：在中央页上方和下方弯曲收起。
5. **内容层**：标题、摘要、标签、时间、缩略图和状态标记。

### 4.2 元素语义

| 视觉元素 | 产品含义 | 主要操作 |
| --- | --- | --- |
| 中央展开纸页 | 当前聚焦笔记 | 点击打开、长按选择 |
| 上下弯曲纸页 | 上一篇与下一篇 | 点击跳转、上下滑动 |
| 两侧刻度 | 卡轮位置与运动反馈 | 跟随页面移动 |
| `2 / 18` 位置指示 | 当前索引与笔记总量 | 按住拖动可快速定位 |
| 顶部搜索拉手 | 收起的全局搜索 | 点击或下拉展开 |
| 左侧品牌书脊 | 产品身份与容器边界 | 通常固定，不承担高频操作 |
| 右侧工具节点 | 本地助手与设置 | 点击进入对应页面 |
| 右下圆弧 | 唯一的新建入口 | 点击新建笔记 |
| 陶土色图钉 | 置顶状态 | 状态提示，菜单中操作 |

### 4.3 顺序规则

- 置顶笔记优先。
- 其余笔记按更新时间倒序。
- 卡轮不提供排序、筛选或视图切换。
- 相邻页必须让用户理解继续滑动的方向。
- 长列表必须提供快速索引，不能要求逐篇滚动。

## 5. 视觉系统

### 5.1 色彩

整体采用温暖的浅色纸面与冷静的蓝灰机械结构。陶土色只作为品牌和重要状态的微量强调。

| 令牌 | 建议值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F1EEE7` | 页面底色、装置背景 |
| `paper-primary` | `#FAF8F2` | 当前展开纸页 |
| `paper-secondary` | `#F3F0E9` | 相邻页、弱内容面 |
| `ink` | `#203442` | 标题、正文、主要图标 |
| `muted` | `#60717D` | 时间、说明、弱文本 |
| `mechanical-blue` | `#587086` | 主操作、刻度、定位节点 |
| `line` | `#C8CDCE` | 纸页边线、分割线、刻度 |
| `terracotta` | `#A76649` | 图钉、品牌微标、少量警示 |
| `danger` | `#A45D59` | 永久删除、失败 |
| `shadow` | `#263847` | 仅以 6%–10% 透明度使用 |

约束：

- 常规主按钮不得使用陶土色或危险色。
- 不使用高饱和渐变。
- 不使用玻璃拟态。
- 图片可以保留真实色彩，但在卡轮预览中应避免过亮、过饱和。

### 5.2 字体

采用「衬线标题 + 无衬线功能文字」。

- 笔记标题：Songti SC、Noto Serif CJK SC 或系统衬线字体。
- 正文摘要：PingFang SC、Noto Sans CJK SC 或系统无衬线字体。
- 时间、计数和刻度：无衬线字体，可使用略窄字面。
- 按钮、设置项、错误说明和权限文案：统一使用无衬线字体。

建议字号：

| 内容 | 建议字号 |
| --- | --- |
| 当前笔记标题 | 28–32sp |
| 相邻笔记标题 | 18–21sp |
| 正文摘要 | 16–17sp |
| 标签 | 13–14sp |
| 时间与计数 | 13–15sp |
| 品牌文字 | 24–28sp |

不应让所有界面都使用宋体。设置、权限和模型管理等高信息密度页面需要保持无衬线字体的效率。

### 5.3 形状

- 纸页接近直角，只使用 2–6dp 的轻微圆角。
- 搜索拉手使用连续曲线和凹槽。
- 主要工具使用圆形或半圆形机械节点。
- 新建入口从屏幕边缘伸出，不使用普通悬浮按钮造型。
- 标签使用细描边紧凑胶囊。
- 状态标记优先使用图钉、刻度点、短线和小三角。
- 避免重新回到“所有内容都是 16dp 圆角卡片”的通用设计。

### 5.4 材质与阴影

界面可以有轻微纸张感，但不能成为真实纸张模拟。

- 纸纹透明度建议不超过 1%–2%。
- 使用静态低频纹理，避免影响文字边缘。
- 主要层级由遮挡关系、边线和位置建立。
- 阴影建议控制在 6%–10% 透明度。
- 不使用皮革、木纹、金属锈迹、真实缝线或厚重投影。

### 5.5 建议尺寸

| 元素 | 建议尺寸 |
| --- | --- |
| 左侧品牌轨道 | 56–64dp |
| 右侧工具轨道 | 52–60dp |
| 当前纸页可用宽度 | 屏幕宽度的 72%–78% |
| 相邻页露出高度 | 52–72dp |
| 圆形工具节点 | 48–52dp |
| 新建入口可见命中区 | 不小于 72dp |
| 页面基础间距 | 4、8、12、16、20、24、32dp |

## 6. 主页交互规范

### 6.1 浏览

- 上下滑动一次移动一篇笔记。
- 中央页经过定位点时展平并轻微放大。
- 上下相邻页弯曲收起，只保留标题、时间和必要状态。
- 页面定位完成时提供轻量触觉反馈。
- 点击相邻页可以直接将其定位到中央。

### 6.2 打开笔记

点击中央页后：

1. 上下相邻页向屏幕边缘退开。
2. 当前页逐渐展平。
3. 当前页扩展到全屏。
4. 编辑工具从纸页边缘或底部标尺区域进入。

该过渡应成为 FKNotes 的核心品牌动效之一。

### 6.3 搜索

搜索采用顶部拉手展开，但必须同时支持点击和下拉。

展开状态：

- 搜索纸带从顶部拉出。
- 用户点击输入区后才聚焦并弹出键盘。
- 展示匹配数量和清除入口。
- 卡轮只保留匹配笔记。
- 退出搜索后恢复原来的卡轮位置。
- 搜索范围遵循功能清单：标题、可见正文、标签、附件名、OCR 和转写元数据。

搜索结果摘要不得出现 Markdown 标记、附件文件名或图片占位文字。

### 6.4 快速定位

当笔记数量较多时，用户可以按住位置指示或侧边刻度拖动。

- 拖动时卡轮快速滚动。
- 中央显示放大的标题和时间预览。
- 松手后定位到最近的一篇笔记。
- 位置指示始终显示当前索引和总数。

### 6.5 新建笔记

- 右下圆弧是主页唯一的新建入口。
- 位于系统安全区上方。
- 点击后圆弧向内推动并推出一张空白纸页。
- 空状态也使用同一个入口，不增加第二个按钮。
- 长按新建不增加隐藏快捷菜单，避免降低可发现性。

### 6.6 本地助手与设置

- 固定在右侧工具轨道。
- 保持至少 44×44dp 命中区域。
- 图标使用简洁线性或低填充风格。
- 本地助手使用双星语义；设置使用滑杆或清晰的设置语义。
- 不在首页加入账号、同步状态或推广信息。

### 6.7 图片笔记

- 当前页按照正文顺序预览所有可见图片，不另造右侧缩略图。
- 图片块占满正文栏，图像高度完全根据原始宽高比自然计算；大图等比缩小，不设置独立的固定像素宽高。
- 图片不设置固定高度或裁切窗口，卡轮自身负责内容截断与底部渐隐。
- 图片使用冷白纸面相框、细描边、轻纸影和机械蓝短线节点，与正文卡片共享视觉语言。
- 图片读取失败时使用中性纸面占位。
- 正文区域必须保留足够宽度。
- 相邻折叠页只保留标题，不展示复杂图片内容。

## 7. 主页状态

### 7.1 普通浏览

- 中央显示一篇完整预览。
- 上下各露出至少一篇相邻笔记。
- 位置、置顶和图片状态清楚可见。

### 7.2 搜索展开

- 顶部搜索纸带展开。
- 卡轮实时过滤。
- 无结果时保留搜索条件，并在卡轮轴心显示明确的无结果说明。

### 7.3 批量选择

卡轮不适合直接承载大量复选框。长按中央页后，界面进入「展平模式」：

1. 卡轮停止滚动。
2. 弯曲纸页逐渐展平。
3. 页面变为紧凑的平面多选栈。
4. 每张纸页左侧出现选择孔位。
5. 顶部显示选中数量、退出和全选。
6. 底部显示批量置顶、取消置顶和永久删除。
7. 完成或退出后重新卷回卡轮。

批量删除必须二次确认，并明确提示永久删除、无法从回收站恢复。

### 7.4 空状态

- 保留卡轮轴心或空的纸页插槽。
- 显示简短说明，例如“这里还没有笔记”。
- 仅保留右下同一个新建入口。
- 不额外增加第二个“新建笔记”按钮。

### 7.5 加载与失败

- 加载时可以使用刻度定位动画，但必须附带文字。
- 缩略图失败使用中性占位。
- 初始化失败不能进入卡轮主页。
- 操作忙碌时禁用重复输入，并通过定位点或纸页状态表达。

## 8. 动效与触觉

### 8.1 时间建议

| 动效 | 建议时间 |
| --- | --- |
| 卡轮切换与定位 | 180–240ms |
| 当前页展开为编辑器 | 260–320ms |
| 搜索纸带展开 | 180–240ms |
| 多选展平 | 220–280ms |
| 标签、状态和轻提示 | 120–180ms |

### 8.2 动效原则

- 使用快速收敛的缓动，不模拟缓慢真实机械。
- 页面定位时可提供一次轻触觉反馈。
- 连续快速滚动时不对每一页重复强震动。
- 不添加持续摇摆、漂浮或纸张抖动。
- 动效结束后必须落在稳定、像素清晰的状态。

### 8.3 减少动态效果

开启系统减少动态效果后：

- 关闭明显的纸页弯曲和透视旋转。
- 卡轮退化为普通纵向分页。
- 页面打开使用淡入和位移。
- 所有功能和信息保持完整。

## 9. 核心组件

后续设计应优先形成以下可复用组件：

1. `PaperShell`：应用纸面外壳。
2. `BrandSpine`：左侧品牌书脊。
3. `RolodexViewport`：纵向卡轮视窗。
4. `ActiveNoteSheet`：中央展开纸页。
5. `AdjacentNoteBand`：相邻弯曲纸带。
6. `IndexTicks`：侧边刻度与快速索引。
7. `SearchPullHandle`：顶部搜索拉手。
8. `ToolNodeButton`：助手和设置节点。
9. `CreateArcButton`：右下圆弧新建入口。
10. `PinMarker`：置顶图钉。
11. `PaperTag`：细描边标签。
12. `FlattenedSelectionStack`：批量选择展平栈。
13. `ConfirmationSheet`：永久删除与高风险操作确认纸面。

每个组件必须设计正常、按压、禁用、加载、错误和无障碍状态。

## 10. 其他页面的延展

### 10.1 富文本编辑器

主页中央纸页展开后直接成为编辑器。

- 标题和正文位于展开纸面。
- 富文本工具表现为底部抽拉标尺。
- 图片、录音和 AI 是纸页边缘工具槽。
- 标签从侧边抽出。
- 图片点击后进入独立操作面，不在顶部固定删除按钮。
- 保存状态以低存在感刻度或文字表达。

### 10.2 本地助手

采用「纸条传送机构」：

- 用户消息和 AI 回复表现为宽度不同的纸条，而不是彩色聊天气泡。
- 引用笔记像插入卡槽的引用页。
- AI 建议写回时生成独立预览纸。
- 用户确认后，预览纸才滑入当前笔记。
- 工具写入失败时纸条停留并显示明确原因。

### 10.3 设置与本地数据

采用「索引抽屉」：

- 每个设置分组是一张纵向索引页。
- 点击后向右拉开进入详情。
- 开关、单选、权限说明仍使用标准且可识别的 Material 交互。
- 纸械语言主要用于页面结构和过渡，不把每个控件设计成机械零件。

### 10.4 本地模型

采用「卷轴刻度」表达下载与存储：

- 下载进度沿刻度移动。
- 清楚显示模型大小、速度、剩余时间和状态。
- 暂停、继续和删除使用标准图标与文字。
- 权限缺失、空间不足和下载失败必须有明确文字。

### 10.5 备份与恢复

- 导出可以表达为把一组纸页装入封套。
- 恢复可以表达为从封套重新插入纸页。
- 动画只是辅助，文件位置、覆盖范围和风险说明必须优先。
- 恢复和覆盖操作必须确认。

### 10.6 制作分享图

采用「排版与打印工作台」：

- 纸张比例和主题选择。
- 内容裁切与图片窗口。
- 预览纸面。
- 生成完成后从底部推出最终分享图。

### 10.7 应用锁与隐私遮罩

- 锁定状态表现为卡轮被纸面护罩覆盖。
- 隐私遮罩只展示品牌和“内容已隐藏”。
- 系统认证入口保持标准、明确，不设计自有机械密码盘。

## 11. 多语言与无障碍

### 11.1 多语言

- 中文可以使用左侧竖排“非空笔记”。
- 英文模式使用旋转后的 `FKNOTES` 或品牌标记，不逐字母竖排。
- 按钮宽度允许英文文案增长。
- 日期、时间、文件大小和模型速度遵循本地化格式。

### 11.2 无障碍

- 语义顺序保持与笔记排序一致，不能按视觉层叠顺序错乱。
- 屏幕阅读器将卡轮暴露为线性笔记列表。
- 所有手势必须有按钮或点击入口替代。
- 文字和图标满足对比度要求。
- 缩略图使用笔记附件描述或可理解的替代文本。
- 动效和触觉遵循系统辅助功能设置。

## 12. Flutter 实现建议

主页不需要真正的 3D 引擎，可以使用 Flutter 的二维变换和自定义绘制实现。

建议结构：

- 使用 `PageView.builder` 或自定义纵向滚动容器构建卡轮。
- 使用 `viewportFraction` 控制相邻页露出比例。
- 根据页面与中心点的距离计算缩放、位移和弯曲程度。
- 使用 `CustomPainter` 绘制刻度、定位点和轨道。
- 使用 `ClipPath`、`Transform` 或轻量透视表现纸页弧度。
- 图片区域使用 `RepaintBoundary` 隔离。
- 仅构建当前页及有限的上下相邻页。
- 使用 `ImageCache` 和稳定缩略图尺寸避免滚动抖动。
- 批量选择模式切换到更适合多选的平面虚拟列表。

实现时应优先验证：

1. 低端 Android 设备上的滚动稳定性。
2. 图片笔记切换时的解码和内存占用。
3. 长标题、长英文和大字体模式。
4. 系统返回、键盘和搜索焦点行为。
5. 减少动态效果和屏幕阅读器模式。

## 13. 风险与护栏

### 13.1 主要风险

- 单篇聚焦降低了同时扫描大量笔记的效率。
- 顶部下拉搜索的发现性低于普通搜索框。
- 真实感过强会让产品显得复古或主题化。
- 弯曲和透视可能损害文字清晰度。
- 将卡轮强行扩展到所有页面会造成交互疲劳。
- 图片加载和连续变换可能影响低端设备性能。

### 13.2 必须遵守的护栏

- 长列表必须提供快速索引。
- 搜索拉手必须可以直接点击。
- 批量操作必须切换到高效率展平模式。
- 中央页文字不进行会损害清晰度的透视变换。
- 除主页或需要聚焦浏览的场景外，不强制使用卡轮。
- 工具控件保持标准语义，不做过度机械化改造。
- 不用纸张隐喻隐藏权限、错误、永久删除或 AI 写入风险。

### 13.3 明确禁止

- 过于明显的纸张颗粒。
- 真实皮革、木桌、金属锈迹和装饰铆钉。
- 厚重投影和高饱和渐变。
- 所有页面都使用卡轮。
- 关键操作只支持手势。
- 为了视觉弧度压缩正文可读面积。
- 将英文逐字母竖排。
- 重新引入底部导航、分类页或重复的新建入口。

## 14. 验证顺序

正式扩展到全量界面前，先完成并验证主页四个关键状态：

1. 普通卡轮浏览。
2. 搜索展开与搜索结果。
3. 长按进入批量选择和永久删除确认。
4. 空状态、加载状态与缩略图失败。

主页状态通过后，按以下顺序延展：

1. 富文本编辑器与主页展开过渡。
2. 编辑器内图片、录音和 AI 写入确认。
3. 本地助手。
4. 设置、本地数据和应用锁。
5. 本地模型、传输任务与存储。
6. 分享图工作台。

## 15. 设计验收清单

- [ ] 是否仍然一眼可见当前笔记和相邻笔记？
- [ ] 是否无需说明就能理解上下滑动？
- [ ] 搜索是否可以通过点击发现，而不只依赖下拉？
- [ ] 是否能够快速跳转到长列表中的任意位置？
- [ ] 新建入口是否唯一且位于安全区上方？
- [ ] 长按选择是否进入高效率的展平模式？
- [ ] 永久删除和 AI 写入是否明确确认？
- [ ] 图片、录音和纯文字笔记是否保持统一结构？
- [ ] 中文、英文和大字体是否均可用？
- [ ] 减少动态效果后是否仍能完成全部操作？
- [ ] 纸张弯曲、刻度和阴影是否表达状态而非纯装饰？
- [ ] 是否避免把所有页面机械化或拟物化？
- [ ] 低端 Android 设备是否保持稳定滚动？

## 16. 最终定义

「静谧纸械」不是一张主页概念图的复制模板，而是一套界面物理规则：

- 内容以纸页承载。
- 顺序以卡轮表达。
- 位置以刻度确认。
- 操作从边缘进入。
- 当前内容在中央展开。
- AI、恢复和删除等高风险行为通过独立纸面保持可控。

后续设计只有在同时满足「有辨识度、操作简单、状态透明、可以实现」时，才视为符合该方向。
