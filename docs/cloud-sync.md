# FKNotes 手动云同步

## 产品边界

- 云同步默认不启用，也没有定时器、后台任务或启动时自动请求。
- 用户必须先配置 S3 或 WebDAV，并手动点击“立即同步”。
- 同步内容包括 SQLite 用户数据库、笔记附件、缩略图、聊天图片和可迁移设置。
- 下载模型、模型断点文件、推理缓存、转写临时文件、恢复草稿、应用锁配置和云端账号配置始终排除。
- 云端账号信息只保存在应用私有目录的 `settings/cloud-sync.json`，恢复其他设备的备份不会覆盖本机账号。

云端对象使用现有 `.fknotes.zip` 完整备份格式，包含逐文件 SHA-256 和整体内容指纹。当前不额外进行端到端加密，因此连接强制使用 HTTPS，并应由用户选择可信的云存储服务。

## 同步协议

远端固定维护两个对象：

```text
latest.json
snapshots/<revision>.fknotes.zip
```

上传时先写入带唯一 revision 的备份，再发布 `latest.json` 指针；新指针成功后才清理旧快照，避免上传中断破坏上一份可用数据。下载时先读取清单，然后校验归档长度、归档 SHA-256、内部清单和数据库结构，全部通过后才事务性替换本机数据。恢复失败会回滚到同步前的数据。

每次同步都会计算稳定的用户数据内容指纹：

1. 本机与云端指纹相同：不传输归档，只更新同步状态。
2. 只有本机相对上次同步发生变化：上传本机快照。
3. 只有云端相对上次同步发生变化：下载并恢复云端快照。
4. 两端都变化，或首次连接已有云端数据：停止同步，由用户选择“保留本机”或“使用云端”。

## WebDAV

配置项包括 HTTPS 服务器地址、用户名、密码和远程目录。连接测试会使用 `PROPFIND` 检查服务，然后执行临时对象的 `PUT`、`GET` 和 `DELETE`，确认实际读写权限。客户端不会绕过 TLS 证书校验，也不会把认证信息跟随重定向发送到其他地址。

## S3

配置项包括 Endpoint、Region、Bucket、Access Key ID、Secret Access Key、对象前缀和 Path-style 开关。实现使用 AWS Signature Version 4，并兼容常见的 S3 兼容对象存储和 MinIO。

最小对象权限为同步前缀下的：

- `s3:GetObject`
- `s3:PutObject`
- `s3:DeleteObject`

连接测试不依赖 `s3:ListBucket`，会直接写入、读回并删除唯一的临时探针对象。

## 验证

提交前至少执行：

```bash
flutter analyze
flutter test
flutter build apk --release
```

发布前应分别使用真实 WebDAV、AWS S3 或兼容 S3 服务验证错误凭据、只读权限、大附件、网络中断、首次同步冲突、双端冲突和恢复回滚。
