# 非空笔记品牌资产

品牌标志延续“笔记本中已有内容”的识别语义，以完整深墨描边、层次书脊、暖白纸页和轻微纸面投影呼应应用内的卡片主题：

- 机械蓝 `#587086`：主品牌色与应用主操作色
- 深墨色 `#203442`：轮廓、正文与小尺寸细节
- 纸张色 `#FAF8F2`：笔记页
- 画布色 `#F1EEE7`：应用图标和启动页背景
- 陶土色 `#A76649`：书签点缀，不作为大面积主色

源文件：

- `fknotes_icon.svg`：带画布背景的完整应用图标
- `fknotes_mark.svg`：与启动画布同色的独立品牌标志，避免系统渲染透明度差异
- `fknotes_wordmark.svg`：横向品牌字标

更新源文件后，在仓库根目录运行：

```sh
./tool/generate_app_icons.sh
```

脚本会统一生成 Android、iOS、macOS、Web、Windows 图标，以及 Android/iOS 启动资源。不要单独手工修改生成的 PNG 或 ICO。
